# Personal Codex Defaults

## Documents And PDFs

When creating outgoing documents, letters, faxes, or PDFs for the user, use this filename pattern by default:

```text
YYYY-MM-DD_OUT_TYPE_CONTACT_SUBJECT.pdf
```

Use terminal-friendly filenames:

- Use `OUT` for outgoing documents and `IN` for incoming documents.
- Use types such as `FAX`, `BRIEF`, `EMAIL`, `RECHNUNG`, or `ANTRAG`.
- Put the contact or organization after the type.
- Put a short, descriptive subject at the end.
- Replace spaces with hyphens.
- Avoid umlauts and special characters where practical.

Example:

```text
2026-06-07_OUT_FAX_Musterfirma_Template-Test.pdf
```
